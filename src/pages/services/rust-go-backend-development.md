## Production backend services

I design and build backend services in Rust and Go for international teams working on infrastructure, developer tools, and performance-sensitive products. I focus on clear boundaries, reliable operations, and code that remains maintainable after launch.

## Where I can help

- **HTTP APIs** — Well-defined REST services with validation, authentication, and predictable error handling
- **Async systems** — Concurrent workers, queues, schedulers, and event-driven services
- **gRPC services** — Typed service-to-service APIs using Protocol Buffers
- **Infrastructure software** — Control planes, operators, agents, CLIs, and platform components
- **Performance work** — Profiling, bottleneck analysis, resource efficiency, and latency reduction
- **Modernization** — Incremental replacement of fragile services while keeping delivery moving

## Rust or Go?

Rust is a strong choice when memory safety, predictable performance, and resource efficiency are central requirements. Go is often a great fit for straightforward cloud services, tooling, and teams that value fast compilation and simple deployment. I help choose based on the system's constraints rather than forcing one language everywhere.

## How I work

I begin with the domain and operational requirements, then define the API and service boundaries before implementation. Tests, observability, CI, documentation, and deployment concerns are part of the service from the start—not work left for the end.
